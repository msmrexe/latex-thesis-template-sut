\begin{englishabstract}
Typesetting academic theses and dissertations in Persian requires strict adherence to institutional formatting guidelines, robust bidirectional font configuration in XePersian, and dependable compilation workflows. This template provides a modernized, modular LaTeX framework designed for Master's theses, Ph.D. dissertations, and Bachelor's projects in accordance with Sharif University of Technology (SUT) standards. The system enforces an architectural separation between the internal typesetting engine (\code{`styles/common.tex`}) and the user configuration layer (\code{`styles/custom.tex`}), enabling safe customization of layout elements, math operators, and packages without compromising document stability.

Key technical capabilities include a centralized metadata architecture that propagates thesis information across Persian and English cover pages as well as official administrative forms; an automated bidirectional glossary pipeline that enforces 32-letter Persian Unicode collation rules with dynamic line-wrapping; and bundled automation scripts for exporting standalone single-page approval forms and declarations. Furthermore, the template incorporates a zero-margin PDF inclusion engine for post-defense signed documents, a customized and enhanced BibTeX style (\code{`unsrtabbrv-modern.bst`}) that automatically generates clickable DOI, URL, and arXiv hyperlinks on publication titles, and an integrated multilingual typography system combining XB Niloofar, Sharif Font, and Adobe Caslon Pro. With balanced heading numbering separators, configurable two-column and single-column footnotes, and zero-warning compilation under PDF 1.7 vector standards, this template establishes a reliable and production-ready environment for academic writing.

\end{englishabstract}
